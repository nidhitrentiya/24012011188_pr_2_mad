# 📱 MAD Practical 2 — Android Application

A Kotlin-based Android application developed as part of Mobile Application Development (MAD) practical coursework.

## 🎯 Project Overview

This project demonstrates Android application development using Kotlin and Android Studio. It provides practical experience in developing Android applications, designing user interfaces, and running applications on an emulator or physical Android device.

## ✨ Features

- 📱 Android application development using Kotlin
- 🎨 User-friendly interface
- 🛠️ Developed using Android Studio
- ⚡ Application building and execution
- 📸 Output screenshots for visual demonstration

## 🛠️ Technologies Used

| Technology | Purpose |
|---|---|
| Kotlin | Application programming language |
| Android Studio | Development environment |
| Android SDK | Android development tools |
| Gradle | Build and dependency management |

## 🚀 How to Run the Project

### 1. Clone the Repository

```bash
git clone https://github.com/nidhitrentiya/24012011188_pr_2_mad.git
```

### 2. Open the Project

Open the cloned project in Android Studio.

### 3. Sync Gradle

Wait for Gradle synchronization to finish and download the required dependencies.

### 4. Select an Android Device

Choose an Android emulator or connect a physical Android device with USB debugging enabled.

### 5. Run the Application

Click the **Run ▶** button in Android Studio and view the application on your selected device.
