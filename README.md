# 📱 MAD Practical 2 — Android Application

> A Kotlin-based Android application developed as part of Mobile Application Development (MAD) practical coursework.

---

## 🎯 Project Overview

This project demonstrates Android application development using Kotlin and Android Studio. It provides practical experience in developing Android applications, designing user interfaces, and running applications on an emulator or physical Android device.

The goal of this project is to understand the fundamentals of Android development and gain hands-on experience in building mobile applications.

---

## ✨ Features

- 📱 **Android Application Development**
  - Developed using Kotlin
  - Built using Android Studio
- 🎨 **User Interface**
  - Android-friendly interface
  - Simple and organized design
- ⚙️ **Application Execution**
  - Build and run the application
  - Test the output on an emulator or physical device
- 📸 **Output Screenshots**
  - Visual demonstration of the application
  - Screenshots included in the repository

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/nidhitrentiya/24012011188_pr_2_mad.git
```

### 2. Open the Project

Open the cloned project in **Android Studio**.

### 3. Sync Gradle

Allow Android Studio to download and synchronize the required dependencies.

### 4. Connect an Android Device

You can run the application using:

- An Android Emulator
- A physical Android device with USB debugging enabled

### 5. Run the Application

Click the **Run ▶** button in Android Studio and select your Android device or emulator.
